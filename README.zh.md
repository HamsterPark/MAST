# MAST — 模块化自主扫描探针显微实验工具包

[English](README.md) · **中文**

**硬件支持：** 目前仅支持 Nanonis 控制器（需要编程接口许可证），以及软件 TERS 部分中的部分光学元件。后续计划扩展到其他 STM 控制器和更多光学元件。

**开始使用**

**直接在仪器电脑上使用**

1. 下载 [MAST Windows 安装包](https://github.com/HamsterPark/MAST/releases)，在连接仪器的电脑上安装，然后打开 MAST 启动器。
2. 在启动器中启动主服务。
3. 在同一台电脑上安装 Claude Code 或 Codex。
4. 打开 Claude Code 或 Codex，告诉它：“请使用这台电脑上的 MAST，帮我完成以下实验：……”

**从另一台电脑远程使用**

1. 在仪器电脑上安装 MAST，并打开 MAST 启动器。
2. 在启动器中勾选“远程连接”，设置用户名和密码，然后启动主服务。
3. 在你准备使用的另一台电脑上安装 Claude Code 或 Codex。
4. 两台电脑都安装 Tailscale，并登录同一个 Tailscale 账户。
5. 按照 MAST 启动器中的指南，在仪器电脑上安装 OpenSSH 服务，让另一台电脑能够连接它。
6. 将指南提供的连接信息和密钥复制给另一台电脑上的 Claude Code 或 Codex，告诉它：“请连接仪器电脑，使用 MAST 帮我完成以下实验：……”

实验过程中，可以在 MAST 界面查看进度、手动操作或停止任务。

本仓库提供 **MAST 6.5.0 公开源码快照**，Windows 安装包采用独立版本号。源码公开范围与各版本的验证记录见[验证状态与公开范围](#验证状态与公开范围)。

**连接通用 AI 智能体与原子尺度实验。**

MAST 通过 Nanonis 控制器，为扫描隧道显微实验（STM）提供仪器接口与受约束的执行能力。外置智能体 Harness 负责推理、上下文管理和任务组织；MAST 提供仪器技能、参数检查、观测访问、操作记录与人工介入；已集成的 VISTA-SPM 为智能体组织视觉证据与定量测量。

项目的科学目标，是在针尖、样品与测量条件变化时，持续开展**观察、提出假设、测量和修订解释**。当前研发重点是支撑这一循环所需的实验接口与证据。

## 为什么转向外置智能体与 VISTA-SPM

我们早期自行开发过多智能体编排器、定制实验工作流，以及基于 DINOv3 的专用 STM 视觉模型。**目前已停止开发内置智能体工作流和专用 DINOv3 训练路线。** 当前推荐的分工是：外置智能体 Harness 负责推理与任务组织，MAST 负责仪器执行，VISTA-SPM 支持视觉推理。6.5.0 源码快照保留了早期实现，作为这些探索的记录。

### 让通用模型通过视觉脚手架开展推理

[VISTA](https://arxiv.org/html/2610.02200v1) 已在其评测的交互式视觉环境中表明：通用多模态模型具备很强的视觉推理能力，直接图像访问、无损视觉记忆，以及按需检索和检查观测的工具，能够有效发挥这些能力。这些结果是我们选择通过 VISTA-SPM 将该思路迁移到 STM 的依据。

自行训练专用视觉模型，需要持续投入数据采集、标注、训练算力、调参与验证，资金和时间成本都很高。新的样品、针尖状态、成像对比度和实验任务不断出现，泛化也就始终需要重新检验。随着通用多模态 LLM 的进步，我们判断，将精力投入原始证据访问、标定坐标和定量测量工具，更符合本项目的需要。VISTA-SPM 提供这些科学脚手架，由通用模型解释观测，并在新的实验与样品上持续评估泛化表现。

### 复用外部 Harness 的进步

Harness 是支撑智能体工具调用、上下文管理、任务组织和恢复的运行框架。外部 Harness 的快速迭代，使独立维护一套内置工作流的必要性不断降低：既要重复建设通用能力，也很难持续跟上整个生态的进步。因此，我们将规划与编排交给外置智能体，专注开发其与 MAST 的接口。

**我们的研发重心转向实验层：仪器接口、执行约束、视觉证据、物理量测量、可追溯记录与实验评估。** 目标是以尽可能少的仪器适配，将通用模型和智能体 Harness 的进步引入实验室，并将时间与资源投入更需要实验经验的科学问题。

## 科学背景与实验挑战

STM 测量导电针尖与样品之间的量子隧穿。在典型恒流成像中，反馈系统调节针尖高度以维持设定电流，得到的原子尺度图像同时受到表面几何形貌与电子结构的影响。扫描隧道谱（STS）测量电流或微分电导随偏压的变化；将微分电导解释为样品局域态密度，需要关于针尖、隧穿势垒、温度和测量条件的近似成立。参见 [Binnig 等](https://doi.org/10.1103/PhysRevLett.49.57)与 [Tersoff–Hamann 理论](https://doi.org/10.1103/PhysRevB.31.805)。

自主 STM 需要在研究样品的同时建立可信的测量条件。针尖末端的原子构型、化学状态和电子态通常无法直接观测；图像与谱线约束了可能的针尖—样品状态，但往往不能给出唯一解释。扫描、脉冲、接触和物质转移又可能在实验过程中改变这些状态。

| 物理特征 | 对实验决策的要求 |
|---|---|
| **部分可观测** | 对针尖与样品状态保留可检验的假设，通过重复扫描、参考测量和对照区分不同解释。 |
| **强非线性** | 隧穿电流对距离高度敏感；依据当前标定与工作条件选择动作，并明确参数边界。 |
| **非平稳** | 热漂移、压电蠕变、吸附与针尖变化会改变位置或响应；在实验过程中持续核对空间配准与测量条件。 |
| **历史依赖** | 压电迟滞、先前的脉冲、接触与物质转移影响后续行为；保留既往操作的顺序、时间和结果。 |
| **操作改变系统** | 修针与原子操纵主动改变隧道结或表面，测量本身也可能扰动样品；评估物理后果，并在操作后重新检查状态。 |

一张分辨清晰的图像，并不足以证明针尖适合谱学测量。异常谱线可能需要排查针尖态、充电、[针尖诱导能带弯曲](https://doi.org/10.1103/PhysRevLett.70.2471)、反馈或噪声的影响。有效对照包括改变测量条件、复测参考区域，或在调理针尖后重复测量；仪器标定、样品条件与操作员授权共同确定可采用的对照。

等待、修针和复测参考区域的时机依赖实验经验。将这些判断用于自主工作流，需要把通用 STM 原理与具体仪器的标定、操作规程和现场观测结合起来。

MAST 的研究目标是支持完整的实验循环：

**观察 → 提出假设 → 设计对照 → 受约束地执行 → 检查针尖与样品变化 → 补充证据并修订解释 → 选择下一步测量。**

这一目标将 STM 实验经验与部分可观测决策、在线系统辨识和主动学习联系起来。它描述项目的研究方向；本次发布所具备证据的能力，以实机记录与验证状态表为准。

已发表的[强化学习原子操纵研究](https://www.nature.com/articles/s41467-022-35149-w)和[集成式 STM 自动化研究](https://doi.org/10.1021/acs.nanolett.5c04982)提供了相关实验背景。[自驱动 SPM](https://doi.org/10.1021/acs.accounts.6c00273)与 [AI 辅助 SPM](https://doi.org/10.1016/j.asi.2026.100003)综述进一步讨论了从单项自动化走向闭环实验的研究方向。

<details>
<summary>仪器条件与测量背景</summary>

面向低能谱学的低温、超高真空 STM，将高灵敏度隧道结与严格的环境控制结合起来。典型量级取决于样品、测量任务和仪器。

| 条件 | 实验意义 |
|---|---|
| 数埃量级的针尖—样品间距 | 电流近似满足 $I \propto e^{-2\kappa z}$，对距离高度敏感。其中 $z$ 为间距，$\kappa$ 取决于有效势垒；针尖与样品电子态也影响实际响应。 |
| 皮安至纳安量级电流 | 常见信号约为 $10^{-12}$ 至 $10^{-9}$ A；前置放大器、接地、线缆与带宽共同决定测量噪声。 |
| 开尔文或毫开尔文温度 | 冷却减小热展宽；谱学测量仍需关注热平衡与电子温度。 |
| 超高真空 | 减少残余气体吸附，支持洁净表面与长时间测量；针尖状态仍可能发生变化。 |
| 机械与电学隔离 | 隔振、屏蔽和滤波用于抑制隧道结位移与电信号扰动。 |
| 数小时或更长时间的稳定性 | 重复谱学与映射要求在漂移和蠕变中维持空间配准及可比较的针尖条件。 |

电流量级可参见[单分子测量综述](https://doi.org/10.1021/nn103298x)。已发表的仪器实例包括 [10 mK 扫描探针设施](https://www.nist.gov/publications/10-mk-scanning-probe-microscopy-facility)和[面向微电子伏隧穿分辨率的测量系统](https://doi.org/10.1063/5.0005320)，这些指标属于所引文献中的仪器。STM 也可在室温、空气或液体中工作，低温与超高真空是具体实验条件的选择。[Yothers 等](https://doi.org/10.1063/1.4974271)讨论了漂移与扫描器非线性的校正。

</details>

## 核心能力与系统架构

当前推荐的分工是：外置智能体 Harness 负责推理与任务组织，MAST 提供仪器后端与执行检查，VISTA-SPM 提供视觉记忆和测量工具，Nanonis 控制器承担底层反馈与仪器控制。

**研究者 → 外置智能体 / Harness → MAST 工具与执行检查 → Nanonis / STM**

**仪器数据 → VISTA-SPM：归档、检查与测量 → 外置智能体推理**

下表中的源码入口对应 6.5.0 快照保留的仪器基础能力。VISTA-SPM 的视觉能力已集成到当前 MAST，其公开参考实现与验证记录见对应仓库。

| 实验需求 | 实现机制 | 实现或使用入口 |
|---|---|---|
| 接入外置智能体 | 技能发现、异步作业、请求去重、冲突检查及重启后的状态处理 | [外部作业](MASTv2/mast/api/ext/jobs.py)、[Claude Code 集成](integrations/claude-code/README.zh.md) |
| 执行有明确边界的物理操作 | 参数与 SI 数量级校验、执行模式检查、仪器占用权管理及中止处理 | [执行上下文](MASTv2/mast/core/execution_context.py)、[安全检查](MASTv2/mast/core/safety.py) |
| 将推理与近期观测关联 | 缓冲与监控层提供观测年龄和扫描进度 | [缓冲服务](MASTv2/mast/buffer/service.py)、[快照中的观测工具](MASTv2/mast/agents/_shared/buffer_tools.py) |
| 检查与测量视觉证据 | 持久图像、标定坐标、局部检查、剖面、配准与定量读出 | [VISTA-SPM](https://github.com/HamsterPark/VISTA-SPM) |
| 检测和处理通信故障 | 控制器协议读取、超时处理、重连与轮询回退，以及明确的流式传输结束状态 | [控制器协议](MASTv2/mast/core/nanonis_patch.py)、[界面通信](frontend/src/lib/) |

React 操作员界面用于监控、手动操作、介入和中止。手动与外部执行路径复用执行检查；仪器占用权在进程内管理。[审阅指南](AGENTS.zh.md)将快照实现对应到回归测试。

## 配套项目与实验推理

**表征本身就是推理的一部分。** 保留 STM 图像的坐标、测量条件与操作历史，使其能够持续支持实验决策。重新检查早期观测，有助于比较不同解释、进行空间配准，并选择有信息量的对照。

[VISTA-SPM](https://github.com/HamsterPark/VISTA-SPM) 是已集成到当前 MAST 的视觉推理层。它将 [VISTA](https://arxiv.org/abs/2610.02200) 的思路与图像档案、标定坐标、局部检查、物理量读出、剖面、傅里叶分析、特征定位和配准差分结合起来，让通用多模态模型能够在外置智能体会话中持续检查实验证据。

| 项目 | 职责 |
|---|---|
| **MAST** | 外置智能体的仪器后端：技能、执行约束、状态与观测访问、操作记录及操作员交互 |
| [VISTA-SPM](https://github.com/HamsterPark/VISTA-SPM) | 已集成的视觉脚手架与 Python 参考模块，支持通用多模态模型保存、重新检查和测量 SPM 观测 |
| [dsh-spm](https://github.com/HamsterPark/dsh-spm) | DeepSeek Harness 运行时中的 SPM 仪器与科学工具，包括视觉记忆和测量能力的 TypeScript 实现 |
| [STM-Bench](https://github.com/HamsterPark/STM-Bench) | 模拟仪器、科学任务、采集记录，以及基于证据的实验策略评估 |

一种目标工作流是：比较原子操纵前后的扫描，以邻近参照物进行配准，测量位移，再选择能够检验当前解释的后续观测。视觉模块也可用于离线分析归档扫描，并适配其他智能体宿主。

VISTA-SPM 提供公开参考实现，其能力已集成到 MAST，也已移植到 dsh-spm。相应的模拟器结果与集成记录由各自仓库说明。**MAST 6.5.0** 源码快照形成于这次路线转变之前，其中的历史视觉代码及验证记录仍对应原有版本。
